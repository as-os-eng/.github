# AS-OS Engineering

We build **AS-OS** — a self-hosted, local-first agentic operating system that runs real ventures.

It started with one problem: a filmmaker running several businesses at once — a production studio, a tea brand, a clothing label, a home-décor export line — with no team big enough to staff every function that could be automated. AS-OS is the answer: a roster of specialized personas, each owning one domain with its own tools, memory, and model.

## How it's built

- **Personas, each with a real job.** A brand strategist and a researcher get different tools and different memory, by design — not every persona needs every capability, and most shouldn't have it.
- **Two tiers.** A design-time layer handles planning and hard reasoning; an always-on runtime layer handles the domain work that can't wait on a rate limit. Each keeps working when the other is unavailable.
- **Runs on hardware we own.** The reference deployment is a single consumer GPU, not a vendor's cluster.
